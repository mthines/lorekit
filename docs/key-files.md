The annotated file index for LoreKit. This is the canonical, full-detail version
of the **Key files** pointer in the root [`CLAUDE.md`](../CLAUDE.md) — that file
keeps only a short "start here" list and links back to this table for everything
else. Grouped loosely by subsystem in migration/PR order.

Neither existing column could tell the two apart: a dashboard read and an agent read over a Supabase JWT are both `auth_type='jwt'` calling `memory.list`, so splitting on the auth tier would be a guess that mis-attributes the moment an agent uses a JWT. Each transport then applies its OWN default around that validator (`?? 'mcp'` in `mcp-handler.ts`, `?? 'api'` in `router.ts`) — a transport IS a fixed calling surface, so an absent/unrecognised header now records what the transport actually is rather than nothing; an explicit header still overrides it, and the default is retroactive for new traffic only (rows written before it stay NULL). `lorekit_read_activity` is recreated (same signature, so no caller changes) with `client is distinct from 'dashboard'` — `is distinct from`, never `<>`, or every pre-00054 NULL row would silently vanish from the series. **The exclusion is in the METRIC, not the LEDGER**: the events are still written in full, `GET /memories/usage` still totals them, and reversing the decision is one migration rather than re-collecting lost data. Drift across the three non-mirror consumers (the web `rest.ts` constants, the router header, the SQL literal) is guarded by `packages/mcp-core/src/telemetry/usage-client-parity.spec.ts` — the failure mode is silent by construction, since a drifted value is simply ignored by the fail-safe parser |
