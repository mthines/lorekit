#

# offsets are real, not hand-written.
#
# WHY a mint step and not a repository secret: a Supabase access token expires
# (jwt_expiry 86400s locally, 3600s hosted). A stored one is dead within a day,
# and its failure mode is silent — orgs-api.integration self-skips on a
# falsy/rejected credential, so an expired token reports the suite as green
# while testing nothing.
#
# This unlocks the 5 org read-back tests (currently not run at all) and the
# positive usage_events assertion, which needs a non-service caller.
